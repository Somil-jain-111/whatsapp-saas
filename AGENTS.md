## Project Commands

Install:
`npm install`

Run:
`npm run start:local` (local MySQL)

`npm run start:dev` (development PostgreSQL)

Build:
`npm run build`

Test:
`npm test`

Lint:
`npm run lint`

Database migrations:
`npm run migration:run` (uses the active database driver)

Generate local MySQL migration:
`npm run migration:generate`

Generate PostgreSQL migration:
`npm run migration:generate:postgres`

Phase 1/2 seed permissions:
`npm run seed:phase1`
